Blueskyの「無効なハンドル」とは？表示される理由と直し方

自分のプロフィール（または他の人のプロフィール）に⚠無効なハンドルと表示された人向けです。2026年11月21日、 私が実際に確認したケースをもとに書きました。英語版のアプリでは同じ表示が「Invalid Handle」です。

まとめ：何も失われていません。投稿、フォロワー、フォロー中のアカウントはアカウント（DID）に ひもづいていて、ハンドル（名前）にはひもづいていません。この表示は「そのハンドルがあなたのアカウントを指していることを、 Blueskyが確認できなかった」という意味だけです。多くの場合は数分で直せるか、待てば自然に消えます。

1. まず確認：大勢が同時に表示されていますか？

Bluesky側の問題のこともあります。たとえば2026年11月20日、日本時間の17:37〜18:52に「無効なハンドルって何？」という日本語の 投稿がまとまって出ました。.bsky.social のふつうのハンドルの人たちです。同じ日の16:30〜16:49（日本時間）には status.bsky.app に一部サーバーの障害が出ていました（原因が同じかどうかは確認できていません）。 私が翌日に確認したその時のハンドル2つは、どちらも正常に戻っていました。

  • status.bsky.app（Blueskyの障害・メンテナンス情報）を見てください。障害が出ていれば、待つのが一番です。
  • 自分でハンドルを確認し直させるには：設定 → アカウント → ハンドルで同じハンドルを入力して保存。 ハンドルが独自ドメインの場合は「自分のドメインを持っています」を選び、同じドメインを入力して確認し直し、 「（ドメイン）に更新」を押します。

2. ログインはできますか？

できます。ハンドルでログインできないときは、「ユーザー名またはメールアドレス」の欄にメールアドレスを入力してください。 サーバーはメールアドレスで自分のアカウント一覧から探すので、ハンドルが有効かどうかに関係しません（Blueskyのサーバーの ソースコードでそう動くことを確認しました）。ログインしたら、ハンドルを直すか別のハンドルに変えます。

3. ハンドルが独自ドメイン（例：taro.jp）の場合

Blueskyはときどき、そのドメインがまだあなたのアカウントを指しているかを確認し直します。確認するのは、 _atproto.ドメイン のTXTレコード（値は did= のあとに自分のDID）か、サイトの /.well-known/atproto-did ファイルです。そのため、何か月も使えていたハンドルが突然無効になることがあります。 実際のケースで多かった原因：

  • ドメインの期限切れ（または駐車ページ・売り出し中になった）。レジストラで更新し、_atproto のレコードが 消えていたら作り直します。Blueskyのアプリで買ったドメインの場合は、こちらのページ （Blueskyのドメイン販売終了について）も見てください。
  • DNSやサーバーの引っ越しで、_atproto のTXTレコードが新しいDNSに移されていなかった。
  • did= のレコードが2つある（古いものと新しいものなど）。2つあるとBlueskyはどちらも受け付けません。 自分のアカウントではない方を削除します。
  • ワイルドカード（*）レコード：レジストラが転送や駐車ページ用に作ったものが _atproto の代わりに 答えてしまう。_atproto にきちんとTXTレコードを作れば、そちらが優先されます。

どれに当てはまるか調べるには：無料のハンドルチェッカーが Blueskyと同じ問い合わせをして、何を直せばいいか（レコードの正確な値も）表示します。英語ですが、よく出る結果は次のとおりです：

チェッカーの表示意味
The domain … does not exist right nowドメインが今存在しない。ほぼ期限切れです。更新してください。
… looks parked, for sale, or expired駐車ページか売り出し中。まだ自分のドメインか確認してください。
The DNS servers for … are not answeringドメインはあるが、DNSサーバーが応答しない。レジストラでネームサーバーとDNSSECの設定を確認してください。
No TXT record found at _atproto…TXTレコードがない。種類TXT、名前（ホスト）_atproto、値 did=＋自分のDID で作成します。
There are 2 "did=" recordsレコードが2つある。チェッカーが示す、自分のものでない方を削除します。
All good今は問題なし。一時的な失敗でした。アプリでハンドルを保存し直してください（1を参照）。
… is a GitHub Pages / Neocities … address無料サイトのアドレス。DNSレコードは作れないので、ファイルを使います（下記）。
… is this account's old handle; it moved and is now …サーバーを引っ越す前の古いハンドルです。直すものはありません。新しいハンドルを確認してください（4を参照）。

GitHub Pages、Neocities、Netlifyなどのアドレスの場合（例：you.github.io、you.neocities.org）： DNSはサービス側が管理しているので、TXTレコードは作れません。ファイルを使います。アプリで 設定 → アカウント → ハンドル → 「自分のドメインを持っています」→「DNSパネルがない場合」タブ。サイトのいちばん上に .well-known フォルダを作り、 その中に拡張子なしのテキストファイル atproto-did を置いて、中身は自分のDIDだけにします。GitHub Pagesの標準の公開 （Jekyll）はドットで始まるフォルダを除外するので、そのままだと .well-known が公開されません（404）。リポジトリ直下の _config.yml に include: [".well-known"] の1行を書いてください（ファイルがなければ作成）。Jekyllのテーマがあっても なくても使えます。HTMLだけのサイトなら、代わりに空の .nojekyll ファイルでも動きます（2026年11月21日にこのサイトで確認）。 ただしテーマを使っているサイトでは .nojekyll を使わないでください。テーマが効かなくなります。

4. 自分のドメインではない場合

  • 他の人のドメインの下のハンドル（友達、コミュニティ、共有ハンドルのサービスなど）：レコードの管理もドメインの更新も そのドメインの持ち主の仕事です。持ち主に頼むか、別のハンドルにしてください（5を参照）。
  • 別のサーバーのハンドル（アカウントが bsky.social ではないサーバーにある）：ハンドルに答えるのはそのサーバーです。 サーバーが止まっていると、戻るまでハンドルは無効と表示されます。自分で作るDNSレコードはありません。
  • アカウントを別のサーバーに引っ越したばかり（Blacksky、Euroskyなど）：直後に「無効なハンドル」と出るのはよくあることです。 私が見た実際の例（2025年10月〜2026年11月）では、約8〜25分で自然に直りました。何か変える前に30分ほど待ってください。 .bsky.social のハンドルは一緒に移りません。新しいサーバーの名前（例：name.blacksky.app）になるか、自分のドメインを使います。 独自ドメインのハンドルは引っ越し後もそのまま使えます（レコードに入っているDIDは変わらないため）。

5. .bsky.social のハンドルに戻す

いつでもできて、投稿もフォロワーも消えません：設定 → アカウント → ハンドル。最初の画面が「新しいハンドル」の欄で、 最後が .bsky.social になっています（ほとんどの人の場合）。名前を入力して保存を押します。 「自分のドメインを持っています」は逆の操作なので押さないでください。ルール：.bsky.social の前は3〜18文字、 使えるのは英字・数字・ハイフンだけ（アンダースコア _ は使えません）。2024年12月12日以降に自分のドメインに変えた場合、その前に使っていた .bsky.social の名前はあなたのために予約されているので、もう一度入力すれば戻せます。「ハンドルはすでに取得されています」と出たら別の名前にします。 2026年11月21日の実際のケースでも、コミュニティのドメインの下のハンドルが使えなくなった人がこの方法で、同じアカウントのまま 有効なハンドルに戻っていました。

ただし、一時的な不具合のためにハンドルを変えないでください。.bsky.social のハンドルに「無効なハンドル」と出たときや、 大勢に同時に出ているときは、たいていBluesky側の問題で、待てば消えます（1を参照）。まず同じハンドルを保存し直してください。 古い名前がどうなるかは、変え方によって違います。.bsky.social から別の .bsky.social に変えると、 古い名前はすぐに空き、誰でも登録できます（Blueskyが公開しているサーバー（PDS）のソースコードでは、ハンドルは updateHandle で上書きされるだけです。私が確認した2025年・2026年の実際の変更2件でも、古い名前はどちらも再び登録できる状態でした）。 .bsky.social から自分のドメインに変えた場合は、古い名前はそのアカウントのために予約されたまま残り、あとで戻せます （Blueskyのドメインハンドルのガイド（英語）によると、 2024年12月12日以降の変更が対象で、予約に期限はありません。アプリのドメイン設定画面にも「あなたの現在のハンドル…は自動的に予約されたままになります」 と表示されます。私が確認したところでも、その日より後に変えた2件は今も保持されていて、2023年4月に変えた2件は空いていました）。どちらの場合も、古い名前を含むリンク （bsky.app/profile/古い名前、共有した投稿のリンク）は開けなくなるか、空いた名前を取った人につながります。 投稿・フォロワー・これまでのメンションはそのまま残ります（DIDにひもづいているため）。変えるのは、古いハンドルが戻らないときだけにしましょう。 2026年11月23日訂正：以前は「古い名前は必ずすぐに空く」と書いていました。

6. 他の人のプロフィールに「無効なハンドル」と出ている

アカウントが消されたという意味ではありません。アカウントは同じままで、フォローも続いています。フォローを外す必要はありません。 本人に知らせたいときは@メンションを使わないでください：アプリは有効なハンドルのときだけ @名前 をメンションにするので、 相手に通知が届きません。相手の投稿にリプライするか、引用してください。
